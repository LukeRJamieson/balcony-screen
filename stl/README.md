# 3D-printable models

Five STL files, built from the same geometry as the approval page's 3D model.
They are at **real-world size in millimetres** (Z up, flat on the bed, centred),
so scale them in your slicer. Each is a single watertight solid.

| File | Size (L x W x H) | Notes |
|---|---|---|
| `AC_outdoor_unit.stl` | 857 x 333 x 703 mm | Fan guard rings are 14 mm thick at full size |
| `Manikin_1750mm.stl` | 550 x 293 x 1739 mm | Actually 1739 mm tall, as rendered on the page. Rounded feet: use a brim |
| `Weber_kettle_BBQ.stl` | 479 x 479 x 929 mm | Legs are 28 mm diameter at full size; use a brim |
| `Bistro_chair.stl` | 630 x 630 x 835 mm | Print twice |
| `Bistro_table.stl` | 400 x 400 x 380 mm | Prints best upside down on its top |

Small changes made so each prints as one piece (overall sizes unchanged):
the AC fan cowl is a solid ring joined to the guard; the BBQ bowl and lid are
one body, its legs reach the bowl, and the ash catcher and lid handle are
nudged into the body.
